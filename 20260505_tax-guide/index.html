신고 전 핵심 개요

상황을 정확히 파악하고 전략을 수립합니다

핵심 원칙 — 각자 별도 신고

공동명의 임대는 지분 비율에 따라 소득을 분배한 후, 양준모·김지윤 두 분이 각자 근로소득 + 임대소득 합산으로 개별 신고합니다. 하나의 부동산이지만 신고서는 두 장입니다.

계좌 집중 관리 구조 — 신고 시 유의사항
김지윤 계좌로 임대료 수취 + 이자 납입이 모두 집중된 경우 세무상 소득·비용의 귀속은 실제 계좌가 아닌 등기부등본 지분율이 기준입니다. 김지윤 계좌에 전액이 잡혀있어도, 각자 지분율에 따라 소득과 비용을 나누어 신고해야 합니다.
  1. 1
    임대료 수입 배분

    김지윤 계좌에 입금된 연간 임대료 합계를 지분율로 나눕니다.
    예) 연 2,400만원 수취, 지분 50:50 → 각 1,200만원 신고

  2. 2
    이자비용 배분

    김지윤 계좌에서 납입된 대출이자도 지분율로 나눠 각자 필요경비 처리.
    예) 연 이자 1,200만원, 지분 50:50 → 각 600만원 필요경비

  3. 3
    양준모 필요경비 증빙

    양준모는 실제 납입자가 아니므로, 공동투자 계약서 또는 이자납입 사실 확인서를 별도로 준비해두면 추후 소명 시 유리합니다.

    공동투자 계약서 또는 각서 보관 권장
  4. 4
    공동사업장 사업자 등록 여부 확인

    공동명의 임대의 경우 공동사업자 등록 후 공동사업자 소득신고서를 먼저 제출하고, 각자 지분 배분 소득을 수령하여 종합소득세를 신고하는 구조가 정확합니다.

    홈택스 → 공동사업장 → 소득 배분 조회 가능

홈택스 신고 절차 (처음 ~ 끝)

양준모·김지윤 각자 동일한 절차로 진행합니다

STEP 1 — 홈택스 로그인
  1. 1
    홈택스 접속 및 로그인

    www.hometax.go.kr → 상단 [로그인] 클릭

    간편인증(카카오·네이버·PASS 등) 사용 가능 — 공동인증서 없어도 됩니다
  2. 2
    신고 메뉴 진입

    상단 [신고/납부] → [세금신고] → [종합소득세] → [정기신고] 클릭

STEP 2 — 기본정보 및 소득 종류 선택
  1. 3
    신고서 기본정보 확인

    주민등록번호·이름 자동 입력 확인 / 귀속연도: 2025

  2. 4
    소득 종류 선택

    체크: 근로소득 + 사업소득(부동산임대)

    [불러오기] 클릭 — 근로소득 원천징수 내역 자동 조회
  3. 5
    근로소득 확인

    자동 불러온 내용과 원천징수영수증 수치 대조. 연간 총급여·기납부세액 확인

STEP 3 — 부동산임대소득 입력 핵심
  1. 6
    사업장 정보 입력

    사업자등록번호 입력 / 업종코드: 701201 (사무용 건물 임대)
    소재지: 서울 강서구 가양동 한화비즈

    공동사업장인 경우 지분율 입력 항목이 별도 표시됩니다
  2. 7
    수입금액 입력

    2025년 실수령 임대료 합계 × 본인 지분율 = 입력 금액
    예) 월 150만원 × 12개월 = 1,800만원 → 지분 50%이면 900만원 입력

    김지윤: 실제 수취액 기준이 아닌 지분율 기준으로 입력
  3. 8
    필요경비 입력

    단순경비율이면 자동 계산. 간편장부 선택 시 실제 비용 × 지분율 입력
    대출이자·감가상각비·재산세 등 항목별 입력

  4. 9
    보증금 간주임대료 계산 (해당 시)

    (보증금 합계 - 3억) × 1/365 × 임대일수 × 정기예금이자율(2025: 3.5%)

    보증금 3억 초과분만 해당 — 월세만이면 불필요
STEP 4 — 소득공제 및 세액공제
  1. 10
    인적공제 확인

    본인(150만), 배우자(150만), 부양가족 각 150만. 연말정산에서 이미 반영된 공제는 중복 입력 불가

  2. 11
    국민연금·건강보험료 공제

    사업소득 관련 납부 보험료 추가 공제 가능. 홈택스 자동 조회

  3. 12
    기납부세액 확인

    연말정산에서 납부한 세액이 최종 세액보다 많으면 환급. 임대소득 추가로 환급이 추납으로 전환될 수 있습니다.

STEP 5 — 신고서 제출 및 납부
  1. 13
    신고서 미리보기 확인

    소득 합계·공제액·납부세액 최종 확인 후 [신고서 제출] 클릭

  2. 14
    납부 (추가 세액 발생 시)

    홈택스 내 [납부] 또는 인터넷뱅킹 국세 납부 / 기한: 2026년 5월 31일

    세액 1,000만원 초과 시 분납 가능 — 2개월 내 분할 납부
  3. 15
    접수증 저장

    제출 완료 후 접수증 PDF 저장 필수. 이후 [신고내역 조회]에서 재확인 가능

  • 연말정산 납부/환급 내역 회사 발급 또는 홈택스 조회 — 기납부세액 확인용

  • 임대차계약서 사본 임차인·임대료·계약 기간 확인용
  • 김지윤 계좌 임대료 수취 내역 (12개월) 실제 입금액 확인 — 거래내역서 출력
  • 한화비즈 취득가액 자료 분양계약서 또는 등기부등본 + 취득세 영수증
  • 등기부등본 — 지분 비율 확인 양준모·김지윤 지분율 (예: 50:50) 확인
필요경비 증빙 서류 절세의 핵심 — 김지윤 계좌 기준
  • 대출 이자 납입 확인서 (은행 발급) 김지윤 계좌에서 납입 — 양준모 지분율분도 경비 처리 가능. 은행 발급 공식 서류 필수
  • 재산세 납부 영수증 (7월·9월) 한화비즈 해당 호실 재산세 — 위택스 또는 납부 고지서
  • 수선비·관리비 영수증 및 세금계산서 도배·도색, 에어컨 수리 등 — 계좌이체 내역도 가능
  • 화재·임대 관련 보험료 영수증 건물 화재보험, 임대인 배상책임보험 납입 내역
  • 공동투자 계약서 또는 각서 (보관용) 김지윤 계좌 집중 관리 사유 소명 대비 — 양준모 지분 비용 공제 근거

감가상각비 계산 방법
계산 공식 감가상각비 = (취득가액 - 토지분 가액) × (1 ÷ 40) × 지분율

토지·건물 분리 방법
분양계약서상 건물·토지 구분 금액 사용이 우선. 없다면 취득 당시 기준시가(건물) / 공시지가(토지) 비율로 안분 계산.

예시: 취득가 3억, 토지분 1억 → 건물분 2억
감가상각비 = 2억 ÷ 40 = 500만원/년 × 지분 50% = 250만원
추가 절세 전략
  1. 1
    연금저축·IRP 추가 납입

    연금저축 400만 + IRP 300만 = 700만원 세액공제 (13.2~16.5%). 임대소득으로 세율 구간이 높아진 해일수록 효과적입니다.

  2. 2
    연말 전 수선·보수 집행

    12월 내 비용 집행 및 증빙 확보 시 당해 연도 경비 처리 가능. 이듬해로 넘기면 당해 년도 공제 불가.

  3. 3
    납부세액 클 경우 분납 활용

    1,000만원 초과분을 2개월 내 분납 가능. 이자 부담 없이 현금흐름 확보.

  4. 4
    공동 관리 계좌 개설 검토 (내년 이후)

    현재 김지윤 개인 계좌로 임대료·이자를 관리하고 있어 세무 소명 시 복잡해질 수 있습니다. 공동 명의 전용 계좌를 개설하면 이후 신고가 훨씬 명확해집니다.

누락·실수하기 쉬운 주의사항

이것만 지켜도 불필요한 가산세를 막을 수 있습니다

가장 많이 발생하는 실수 임대소득 신고 누락 또는 지분율 미적용으로 소득을 과대·과소 신고. 반드시 등기부등본 지분율을 확인한 후 각자 분배하여 입력해야 합니다.
자주 놓치는 항목
  1. !
    김지윤 계좌 수취액 전액을 김지윤 소득으로 신고하는 오류

    임대료 전액이 김지윤 계좌로 입금되더라도, 양준모 지분율만큼은 양준모 소득으로 각자 신고해야 합니다. 전액 김지윤 신고 시 양준모 소득 신고 누락 + 김지윤 소득 과다 신고 이중 문제 발생.

  2. !
    보증금 간주임대료 누락

    월세 외에 보증금을 받고 있다면 간주임대료 계산 필요. 보증금 3억 초과분 × 3.5% 계산 후 수입에 포함.

  3. !
    감가상각 미신청 시 소급 불가

    감가상각비는 매년 신고 시 선택 적용. 신청하지 않으면 해당 연도분 소멸. 첫 해 반드시 신청.

  4. !
    근로소득 연말정산 공제 항목 중복 입력

    연말정산에서 이미 공제된 항목(의료비·교육비·보험료 등)을 종합소득세 신고 시 이중으로 입력하면 가산세 대상. 홈택스 자동 불러오기 사용 권장.

  5. !
    증빙 없는 비용 임의 계상

    영수증·계좌이체 내역 없는 비용은 불인정. 가산세 + 소득 과소 신고 추징 위험. 의심스러운 비용은 제외.

  6. !
    5월 31일 신고 및 납부 동시 완료

    신고만 하고 납부를 안 하면 납부불성실가산세 발생 (0.022%/일). 신고와 납부를 같은 날 완료.

직접 신고가 어렵다고 느껴질 때 두 분의 근로소득 구간이 모두 높거나(35%~45% 구간), 공동사업장 소득 배분 처리가 복잡하게 느껴진다면, 이번 한 번만 세무사 컨설팅(1회 15~30만원)으로 기준을 잡고 이후 직접 신고 체계를 구축하는 것도 효율적입니다.
