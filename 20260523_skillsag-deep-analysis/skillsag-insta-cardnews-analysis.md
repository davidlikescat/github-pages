## 4. "이거 진짜로 만들 수 있는가" — 제작 방식 역추정

### 4.1 Claude Code Skills의 정체

Anthropic이 2025년 후반부터 밀고 있는 **Claude Code Skills**는 다음 규약이다.

- `SKILL.md` 파일에 YAML frontmatter (`name`, `description`)로 메타데이터 선언
- 본문은 마크다운으로 작성된 "에이전트가 읽는 매뉴얼" + (선택) `references/` 폴더의 추가 컨텍스트
- 사용자가 호출하면 Claude가 SKILL.md를 읽고, 필요에 따라 `scripts/`에 들어있는 실행 코드(Python, Bash 등)를 실행 (Bash 도구 권한 필요)
- `command` 필드(여기선 `insta-card-news`)는 `/insta-card-news` 형태의 슬래시 명령으로 노출

이 스킬은 그 컨벤션을 **거의 교과서적으로** 따른다. 즉, **자체 검증 가능한 형태**의 스킬.

### 4.2 실제 작동 시나리오 (추론)

1. 사용자가 `/insta-card-news "주제 한 줄"` 실행
2. Claude가 SKILL.md 읽고 → `references/cover-patterns.md`, `body-patterns.md`, `closing-patterns.md`에서 패턴 1개씩 선택
3. `references/caption-writing.md` 가이드대로 캡션·해시태그 생성
4. 슬라이드 8장(표지 1 + 본문 6~7 + 마무리 1) 각각에 대해:
   - `scripts/generate_bg.py` 호출 → Replicate API의 nano-banana 모델로 배경 PNG 생성 (사용자 토큰 차감)
   - `assets/templates/base.html` 템플릿에 슬라이드 데이터·배경 합성
   - `scripts/render_card.py`로 HTML → 1080×1350 PNG 렌더 (Playwright/Puppeteer 또는 html2image 추정)
5. `deck.html` + `01.png`~`08.png` + `caption.md`를 작업 폴더에 저장

### 4.3 nano-banana 모델 정체

"nano-banana"는 **Google Gemini 2.5 Flash Image 모델의 별명/코드네임**으로 LMSys/Replicate 커뮤니티에서 통용되는 이름. Replicate에는 비공식 미러가 존재하며 호출당 ~$0.039 수준(2026년 기준). 7장 = $0.27 ≈ **₩370 / 1회**. 합리적인 단가.

### 4.4 재현 가능성

이 패키지 구조는 **누구나 만들 수 있다**. 진짜 가치는 (a) 패턴 라이브러리의 품질, (b) `base.html` + `design-system.md`의 폴리시 수준, (c) caption-writing.md의 한국어 카피 가이드라인이다. 첨부된 Before/After 스크린샷에서 결과물의 일관성·완성도는 풍부해 보이나, **실물을 받아보지 않으면 패턴이 10종이 실제로 있는지, 캐러셀이 두 번 만들어도 다른 그림인지는 검증 불가**.

## 5. "사람들이 실제로 살까" — 유효성 평가
