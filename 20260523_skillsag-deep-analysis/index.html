실행 시나리오 (추론)

  1. 사용자가 /insta-card-news "주제" 호출
  2. Claude가 SKILL.md 읽고 → 표지/본문/마무리 패턴 1개씩 선택
  3. caption-writing.md 가이드로 캡션·해시태그 생성
  4. 각 슬라이드마다 Replicate nano-banana 모델로 배경 PNG 생성 (사용자 토큰 차감, ~₩370/회)
  5. base.html에 데이터 합성 → render_card.py로 1080×1350 PNG 8장 출력
  6. deck.html + 01.png~08.png + caption.md를 작업 폴더에 저장

nano-banana 정체

"nano-banana"는 Google Gemini 2.5 Flash Image 모델의 별명/코드네임으로 LMSys/Replicate 커뮤니티에서 통용되는 이름. Replicate 미러 비공식 호출당 ~$0.039. 7장 = $0.27 ≈ ₩370/회. 합리적 단가.

재현 가능성

패키지 구조 자체는 누구나 만들 수 있다. 진짜 가치는 (a) 패턴 라이브러리의 품질, (b) base.html + design-system.md의 폴리시 수준, (c) caption-writing.md의 한국어 카피 가이드라인이다. 실물을 받기 전엔 검증 불가.
